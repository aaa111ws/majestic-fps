# Majestic RP без фризов: редукс LAWS v2 + урезанная графика

## Скачать

Зелёная кнопка **Code** вверху → **Download ZIP** (~1,2 ГБ). Распакуй ZIP в любую папку.

## 1. Редукс

1. Запусти `SOBRAT.bat`. Он склеит части из папки `parts` в один файл `laws.v2.rar` (около минуты).
2. Открой `laws.v2.rar` через WinRAR или 7-Zip. Пароль: `majestic-mods.ru`
3. Закрой GTA, Majestic и лаунчеры.
4. Зайди в папку с игрой GTA V (там, где `GTA5.exe`), потом в папку `update`.
5. Переименуй свой `update.rpf` в `update.rpf.original`: это бэкап.
6. Скопируй `update.rpf` из архива в эту папку `update`.

## 2. Графика

1. Открой `Документы\Rockstar Games\GTA V\`.
2. Переименуй свой `settings.xml` в `settings.xml.original`.
3. Скопируй туда `settings.xml` из папки `grafika`.
4. Запусти игру и в настройках поставь разрешение под свой монитор. В файле стоит 2560×1080.

## Вернуть как было

Удали новые `update.rpf` и `settings.xml`, а у бэкапов убери `.original` из названия.

> Редукс меняет файлы игры, ставишь на свой риск.

Для ленивых есть `MajesticFPS.exe`, который делает всё сам: запусти и нажми `1`.
